# Rabbit_plugins

BookOasis용 AniList 스타일 상세페이지 렌더러입니다. Detail Studio의 메타데이터 처리 기반을 사용하되, 별도 플러그인 ID `rabbit_plugins`로 동작합니다.

- 플러그인 버전: `3.2.2`
- 1차 개발 상태: 완료
- 라이선스: GNU AGPL v3 (`LICENSE` 참조)

## 1차 개발 범위

### 상세페이지

- 배너 이미지, Colorscape, 표지, 작품 소개를 표시합니다. 배너가 없을 때 표지를 대신 배너로 사용하지 않습니다.
- 제목, 원제, 소개, 추천항목, 관련작품을 표시하고, 장르·태그·작가·출판사·연재상태·권수·연령등급·별점 등은 상세정보에 배치합니다.
- 시리즈 둘러보기가 없을 때 파일포맷을 상세정보에 표시합니다. 메타정보 편집에서는 연재 시작일·종료일, ISBN / Web ID 등을 수정할 수 있고, 그림작가와 쉼표로 구분한 여러 관련 링크도 지원합니다.
- 시리즈 읽기, 즐겨찾기, 컬렉션 추가 기능을 제공합니다.
- 커뮤니티 별점 플러그인이 활성화되면 별을 가리켜 반 칸 단위로 선택하고 저장할 수 있습니다.
- ComicInfo.xml Summary의 이미지 태그 표시를 설정에서 켜거나 끌 수 있습니다. 끄면 해당 이미지와 태그 문구를 표시하지 않습니다.
- 제외 장르와 제외 태그를 쉼표로 설정해 상세정보에서 숨길 수 있습니다.
- 메타데이터 자동 수집을 켜면 스캔 후 비어 있는 도서 정보를 백그라운드에서 채웁니다. Series.db, 리디, 네이버시리즈, 네이버웹툰, 교보문고, 예스24, 카카오페이지, 카카오웹툰, 문피아, 노벨피아를 선택하고 우선순위를 정할 수 있으며, 가져올 필드·표지 수집 대상 유형·기존 값 덮어쓰기를 설정할 수 있습니다. 표지 수집 유형은 BookOasis 속성 관리 목록을 읽어 표시하고, Series.db 분류에 필요한 `manga`, `novel`, `manhwa` 코드는 항상 유지합니다.
- 기존 연재 시리즈에 파일명 `(완결)`인 새 자료가 들어오면 제공처를 다시 조회합니다. 제공처에서도 완결이 확인될 때 연재상태·연재종료일·새 태그만 갱신하며, 기존 태그와 다른 메타데이터는 유지합니다. 제공처에 종료일이 없으면 종료일은 비워 둡니다.
- Series.db 자동 수집은 표지·원제·링크만 반영하고, 외부 제공처는 나머지 필드를 채웁니다. Series.db 후보가 여러 개여도 자동 매칭을 중단하지 않으며, 여러 제공처의 링크는 중복 없이 합쳐 저장합니다.
- 기존 메타데이터와 기존 표지의 덮어쓰기를 각각 켜고 허용할 라이브러리 유형을 지정할 수 있습니다. 유형 선택은 `전체` 또는 Shift 범위 선택을 지원합니다.
- 관리자 상세화면의 메타데이터 검색에서 제목을 직접 검색하고 후보를 선택해 시리즈 전체 권에 적용할 수 있습니다. Series.db 유형을 먼저 확인하고 선택한 외부 제공처를 순서대로 검색합니다.
- 동명 작품의 작가명이 충돌해 자동 적용이 보류되면 관리자 상세화면에 후보와 작가명을 표시하고 수동 검색으로 연결합니다.
- 메타데이터 검색어에 적용할 제거 키워드와 유지 키워드를 각각 설정할 수 있습니다. 유지 키워드는 제거 목록보다 먼저 보호합니다.
- 리디의 판타지·로맨스·로판·무협 소설 e북을 소설 검색에 포함하고 만화 e북은 구분합니다. 리디 웹소설은 `웹소설`을 장르에 저장합니다.
- 시리즈 둘러보기와 다음 이야기에는 검색 결과의 시리즈명이 아니라 파일명에서 추출한 `01권 (한정판)`, `02권 (완결)` 같은 권별 제목을 표시합니다. 파일명에서 권·화 정보를 찾지 못하면 기존 제목을 사용합니다.
- 외부 제공처의 시리즈 제목을 권별 `title_alias`로 덮어쓰지 않고, 기존 별칭에 남아 있는 작품소개 문구만 정리합니다.
- PDF에서 장르와 태그가 같은 값으로 전달되는 경우 상세화면에서 장르를 우선해 태그 중복을 제거합니다.
- ComicInfo의 `Number`를 화수로 읽고 `Volume`이 없으면 화 단위로 표시합니다. `Volume`과 `Number`가 함께 있으면 권별 카드 안에 화 목록을 묶고, 표지 클릭은 목록을 열며 책 아이콘은 해당 권 읽기를 시작합니다.
- `Volume`과 `Number`가 함께 있는 작품은 `Count`가 최대 `Volume`과 같을 때 권수로 해석합니다. 이 경우 화 번호가 1부터 연속되지 않으면 최대 화수와 실제 화수로 `누락`을 표시해, 1화와 247화만 있는 작품을 완결로 잘못 표시하지 않습니다.

### 관련작품과 추천항목

- Series.db의 관계 데이터를 본편, 전작, 후속작, 스핀오프, 외전, 다른 판본, 각색, 기타 순서로 표시합니다.
- Series.db에 연결된 작품이 실제 라이브러리에 스캔된 경우 표시하며, 다른 라이브러리에 있는 작품도 찾습니다. 라이브러리가 만화·소설·도서로 지정되어 있으면 Series.db 작품 유형과 대조해 같은 제목의 다른 유형 작품이 잘못 연결되지 않게 합니다. 유형은 조회 시 라이브러리 설정에서 읽으므로 변경 후 재스캔하지 않아도 됩니다.
- Series.db에 한글 제목이 없더라도 EPUB의 원제와 라이브러리 유형이 일치하면 관련작품을 연결합니다. 같은 원제를 가진 만화·소설 사이의 본편·각색 관계도 각 라이브러리에 작품이 스캔된 경우 표시합니다.
- 추천은 Series.db의 MangaUpdates 추천을 우선 사용하고, 보유한 추천작을 표시합니다. 작가·태그가 비슷한 작품도 더하며, 추천 결과가 없으면 장르나 태그가 겹치는 작품을 무작위로 표시합니다. 관련작품은 추천항목에서 제외합니다.
- Series.db 경로를 설정할 수 있으며, 비워두면 `/app/db/series.full.sqlite`를 사용합니다. 사용자 지정 경로는 BookOasis 컨테이너 내부 경로여야 하고, DB 파일 및 백업을 쓸 수 있는 권한과 공간이 필요합니다. 설정의 최적화 버튼은 백업, 필요 공간 확인, 최적화, 무결성 검사를 수행합니다.
- Series.db 제목 검색 인덱스는 유형 정보도 포함해 `cache/rabbit_plugins_series_index.sqlite`에 생성합니다. 기존 인덱스는 다음 조회 때 자동으로 다시 만들어지며, 책을 재스캔할 필요는 없습니다.
- 새로고침 시 관련작품과 추천항목을 한 번에 불러오고, 결과를 함께 표시합니다.
- 제목 끝의 대괄호 작가명을 정규화해 만화와 라노벨 항목을 찾고, 원제 메타데이터가 비어 있어도 Series.db 원제로 관계를 표시합니다. 추천 조회는 표지 갱신이 바로 보이도록 캐시를 우회하며 표지 URL에 갱신 시각을 포함합니다.
- EPUB OPF의 Calibre `series_index`, EPUB 3 `group-position`, 명시된 전체 권수 필드와 발행일을 읽습니다. PDF는 문서 속성·키워드·파일명에서 명시된 권수와 전체 권수를 읽고, 발행일은 발행/공개로 표시된 날짜만 사용합니다(파일 생성일은 사용하지 않습니다). 전체 Count가 없으면 종료일은 추측하지 않고 비워 둡니다.

### 홈 화면 위젯

- 일반 도서의 신규 도서를 라이브러리별 탭과 가로 카드 목록으로 표시하는 위젯을 제공합니다.
- 라이브러리와 표시 개수는 플러그인 설정에서 지정합니다.

## 설치

플러그인 폴더를 다음 위치에 둡니다.

```text
plugins/metadata/rabbit_plugins/
```

플러그인 매니저의 **저장소 URL 설치**에 `https://github.com/daydreamrabbit/rabbit_plugins`를 입력하고 **저장소 설치**를 누르면 기본 브랜치의 ZIP을 내려받아 설치·활성화합니다. 그다음 BookOasis의 **설정 → 플러그인 관리 → 도서 상세페이지 렌더러**에서 사용할 세션에 `Rabbit Plugins · 상세페이지`를 선택합니다. 기존 Detail Studio 설정과 데이터는 변경하지 않습니다.

홈 화면 위젯을 쓰려면 **설정 → 내 설정**에서 **홈 화면을 플러그인 배치 모드로 전환**을 켜고 저장한 다음, 홈 화면의 **위젯 추가 → 라이브러리별 신규 도서**를 선택합니다. 이 기능에는 BookOasis의 플러그인 대시보드 번들 지원이 필요합니다.

## 라이선스 및 출처

Detail Studio의 기존 상세 데이터 처리 코드를 바탕으로 수정했습니다. GNU AGPL v3 원문은 `LICENSE`에 포함되어 있습니다. 원본 프로젝트는 [daydreamrabbit/detail_studio](https://github.com/daydreamrabbit/detail_studio)입니다.

### 추가 제공처 (3.0.0)

- 설정의 메타데이터 제공처 목록에서 사용할 곳을 선택하고 위아래로 우선순위를 조정합니다. 기존에 저장한 선택은 유지되므로 새 제공처는 직접 체크하고 저장해 주세요.
- 카카오페이지는 `novel`과 `manhwa`, 문피아·노벨피아는 `novel`, 카카오웹툰은 `manhwa`에서 검색합니다. 카카오페이지와 카카오웹툰은 묶음으로 이동하며 웹툰 유형에서 동일 작품의 정보를 병합합니다.
- `시리즈명 [작가명]` 폴더의 작가를 매칭 조건으로 사용합니다. 자동 검색은 제목 일치를 유지하고, 수동 검색은 일부 제목으로도 검색합니다.
- 자동 수집은 우선순위대로 선택한 필드를 채우며 작품 소개도 설정에서 선택할 수 있습니다. 수동 적용에서는 작품 소개도 저장할 수 있습니다.

### 예스24 Open API

예스24 검색을 사용하려면 [예스24 개발자센터](https://developers.yes24.com/docs/apikey)에서 발급받은 API 키를 플러그인 설정의 `예스24 Open API 키`에 입력하고, 제공처 목록에서 예스24를 체크한 뒤 저장하세요. 키가 비어 있으면 예스24 요청은 건너뜁니다. 소설·만화·웹툰 유형은 전자책 카탈로그, 도서 유형은 전체 카탈로그에서 검색합니다. 검색 결과의 예스24 세부 분류를 확인해 라이브러리 유형과 다른 상품은 제외하며, 판타지/무협·로맨스·라이트노벨과 그 하위 분류는 소설로 처리합니다. 장르는 API의 상품 분류에서 가져오고, 판타지/무협·로맨스·BL 웹소설 계열은 소장용 전자책이어도 `웹소설` 장르를 추가합니다. 태그는 선택한 상품을 적용할 때 공개 상품 페이지에서 가져옵니다. 제목의 `화` 또는 `[연재]` 표시는 연재판으로, `권` 또는 번호 없는 제목은 일반 전자책으로 구분합니다. 자동 수집은 로컬 파일명에 맞는 판본을 고르고, 수동 검색에는 두 판본을 구분해서 보여줍니다. 자동 수집은 기존과 동일하게 제목을 정확히 비교하고, 수동 검색은 짧은 제목도 허용합니다.

### 노벨피아 작가 보조 검색

일반 검색에서 작품이 누락되면 작가명 검색, Yahoo 일본·네이버 공개 검색으로 노벨피아 작품 링크를 찾습니다. 별도 검색 서버나 로그인 쿠키는 필요하지 않습니다. 폴더명 `시리즈명 [작가명]`의 작가명도 검증합니다. 작가명이 없어도 공개 작품 페이지의 제목을 확인해 작가를 찾습니다.

검색 결과의 설명을 메타데이터로 저장하지 않습니다. 노벨피아에서 작가 번호와 공개 작품 목록을 조회하고 자동 검색은 제목 일치, 수동 검색은 부분 제목을 허용합니다. 작가 번호는 7일간 보관하며 다시 조회할 때 이름을 검증합니다.

공개 검색의 시간과 페이지 수를 제한하고, 조회 실패를 작품 부재로 확정하지 않습니다. 공개 검색에도 색인되지 않은 작품까지 발견한다고 보장하지 않습니다. `노벨피아 작가 보조 검색 URL`은 SearXNG JSON 검색을 별도로 추가할 때만 쓰는 선택 설정입니다.
