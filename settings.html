Rabbit Plugins 설정 상세 화면과 자동 메타데이터 수집을 한 곳에서 관리합니다.

기본 표시

상세 화면에서 사용할 로컬 데이터와 표시 제외 규칙입니다.

켜면 CBZ/ZIP의 ComicInfo.xml Summary에서 이미지 태그를 읽어 소개에 표시합니다. 끄면 이미지와 태그 문구를 표시하지 않습니다.

BookOasis 컨테이너 안에서 접근할 경로를 입력하세요. 비워두면 /app/db/series.full.sqlite를 사용합니다.

쉼표(,)로 구분해 입력한 태그는 상세정보에서 숨깁니다.

쉼표(,)로 구분해 입력한 장르는 상세정보에서 숨깁니다.

자동 메타데이터 수집

스캔 후 작품을 찾고, 선택한 제공처의 값을 DB에 저장합니다.

메타데이터가 비어 있는 신규 도서를 스캔 후 백그라운드에서 검색합니다. 파일명에 연재가 있으면 리디의 만화 연재 탭을 사용합니다.

손잡이를 끌어 순서를 바꾸고, 체크한 제공처만 검색합니다. 체크하지 않은 제공처는 검색하지 않습니다.

위에 있을수록 우선순위가 높습니다. 정확히 맞는 후보만 선택하며, 선택된 제공처의 값은 우선순서대로 빈 필드를 보완합니다. 링크는 중복을 제거해 합칩니다.

표지 및 덮어쓰기
표지를 가져올 자료 유형
속성 목록을 불러오는 중...

선택한 라이브러리 유형에만 검색 결과 표지를 저장합니다. 전체 선택과 Shift 범위 선택을 지원합니다.

메타데이터 검색에서 직접 선택한 결과를 적용할 때만 사용합니다. 자동 수집의 덮어쓰기 설정과는 별개이며, 관련 링크도 선택한 결과로 교체됩니다. 표지는 기존 표지 덮어쓰기 설정을 따릅니다.

기존 메타데이터를 덮어쓸 자료 유형
속성 목록을 불러오는 중...

기존 값 덮어쓰기를 켠 경우에만 적용됩니다. 전체 또는 Shift 범위 선택을 지원합니다.

기존 표지를 덮어쓸 자료 유형
속성 목록을 불러오는 중...

기존 표지 덮어쓰기를 켠 경우에만 적용됩니다. 전체 선택과 Shift 범위 선택을 지원합니다.

값 변환

들어오는 값을 왼쪽에, 저장할 값을 오른쪽에 입력합니다. 한 줄에 하나의 규칙을 추가하세요.

검색어 정리

메타데이터 검색어를 만들 때만 제거합니다. 쉼표, 세미콜론 또는 줄바꿈으로 구분하세요.

제거 목록에 포함되어도 검색어에 남길 제목 구간입니다. 유지 목록이 제거보다 먼저 적용됩니다.

일반 도서 홈 화면 신규 도서

선택한 라이브러리가 각각 탭으로 표시됩니다. 각 행의 손잡이를 끌어서 탭 순서를 바꿀 수 있고, 각 탭에는 지정한 수만큼 신규 도서 카드가 나옵니다. BookOasis 설정의 ‘내 설정’ 탭에서 ‘홈 화면을 플러그인 배치 모드로 전환’을 켜고 저장한 다음, 홈 화면의 ‘위젯 추가’에서 ‘라이브러리별 신규 도서’를 추가하세요.

Series.db 자동 최적화

관리자만 실행할 수 있습니다. 실행 전 자동 백업을 만들며, 이미 최적화된 DB는 변경하지 않습니다.
